ONLYLEAF RUGS — RECREATED FRONT-END
=================================
1. Extract the ZIP.
2. Open the onlyleaf-rugs-recreated folder in VS Code.
3. Open index.html in Chrome, or use the Live Server extension.

This is a static HTML/CSS/JavaScript front-end recreated from the supplied reference screenshot. The design and layout are responsive. Search, room-category filtering, favorite buttons, currency display and demo cart interactions work locally.

IMPORTANT: Prices/products are sample data. Currency conversion is illustrative only. There is no database, user authentication, real payment processing, stock control, shipping API or production checkout. Do not use for accepting real orders.

Images in assets are cropped from the reference screenshot provided in this conversation to match its visual appearance. Replace them with licensed original product images before commercial launch.
